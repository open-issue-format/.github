# open-issue-format

Holds the long-form name for the [Open Issue Format](https://oif.md).

The specification, validator and agent skill live in
[oifmd/oifmd](https://github.com/oifmd/oifmd).

`profile/README.md` renders on the organisation page once this
repository is public. It links the canonical repository, so publish it
only after that repository is public, or the links dead-end.
